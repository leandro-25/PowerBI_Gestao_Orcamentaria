MEDIDAS DAX — Painel de Gestão Orçamentária e Performance
Crie estas medidas em uma tabela chamada _Medidas. Ajuste nomes se necessário.

Valor Realizado = CALCULATE(SUM(fLancamentosRealizados[Valor]))
Valor Orçado = CALCULATE(SUM(fOrcamento[Valor]), fOrcamento[Cenario] = "Budget")
Valor Forecast = CALCULATE(SUM(fOrcamento[Valor]), fOrcamento[Cenario] = "Forecast")
Desvio vs Orçado = [Valor Realizado] - [Valor Orçado]
Desvio % = DIVIDE([Desvio vs Orçado], [Valor Orçado])
Execução do Orçamento % = DIVIDE([Valor Realizado], [Valor Orçado])
Custos Fixos = CALCULATE([Valor Realizado], dPlanoContas[Categoria] = "Custo Fixo")
Custos Variáveis = CALCULATE([Valor Realizado], dPlanoContas[Categoria] = "Custo Variável")
Despesas Operacionais = CALCULATE([Valor Realizado], dPlanoContas[Categoria] = "Despesa Operacional")
Realizado Mês Anterior =
    CALCULATE([Valor Realizado], DATEADD(dCalendario[Data], -1, MONTH))
Variação MoM = [Valor Realizado] - [Realizado Mês Anterior]
Variação MoM % = DIVIDE([Variação MoM], [Realizado Mês Anterior])
Acumulado Realizado =
    CALCULATE([Valor Realizado], FILTER(ALLSELECTED(dCalendario[Data]), dCalendario[Data] <= MAX(dCalendario[Data])))
Acumulado Orçado =
    CALCULATE([Valor Orçado], FILTER(ALLSELECTED(dCalendario[Data]), dCalendario[Data] <= MAX(dCalendario[Data])))

-- Parâmetros What-If (crie tabelas desconectadas com Enter Data ou Modelagem > Novo parâmetro)
-- ParamPreco[Valor] faixa sugerida: -20% a +20%, passo 1%, padrão 0%
-- ParamCusto[Valor] faixa sugerida: -20% a +30%, passo 1%, padrão 0%
-- ParamVolume[Valor] faixa sugerida: -30% a +50%, passo 1%, padrão 0%

Variação Preço % = SELECTEDVALUE(ParamPreco[Valor], 0)
Variação Custo % = SELECTEDVALUE(ParamCusto[Valor], 0)
Variação Volume % = SELECTEDVALUE(ParamVolume[Valor], 0)
Receita Base = SUMX(fVendas, fVendas[Unidades] * fVendas[PrecoUnitario])
Custo Variável Base = SUMX(fVendas, fVendas[Unidades] * fVendas[CustoVariavelUnitario])
Receita Simulada =
    SUMX(fVendas, fVendas[Unidades] * (1 + [Variação Volume %]) * fVendas[PrecoUnitario] * (1 + [Variação Preço %]))
Custo Variável Simulado =
    SUMX(fVendas, fVendas[Unidades] * (1 + [Variação Volume %]) * fVendas[CustoVariavelUnitario] * (1 + [Variação Custo %]))
Margem de Contribuição Simulada = [Receita Simulada] - [Custo Variável Simulado]
Custos Fixos Base = [Custos Fixos]
Resultado Simulado = [Margem de Contribuição Simulada] - [Custos Fixos Base]
Margem de Contribuição % = DIVIDE([Margem de Contribuição Simulada], [Receita Simulada])
Ponto de Equilíbrio (Receita) = DIVIDE([Custos Fixos Base], [Margem de Contribuição %])

Pareto — % Acumulado =
VAR Atual = [Valor Realizado]
VAR SomaAcumulada =
    SUMX(FILTER(ALLSELECTED(dPlanoContas[Conta]),
        [Valor Realizado] >= Atual), [Valor Realizado])
RETURN DIVIDE(SomaAcumulada,
    CALCULATE([Valor Realizado], ALLSELECTED(dPlanoContas[Conta])))

MODELO DE RELACIONAMENTOS
- dCalendario[Data] 1:* fLancamentosRealizados[Data]
- dCalendario[Data] 1:* fOrcamento[Data]
- dCalendario[Data] 1:* fVendas[Data]
- dPlanoContas[ContaID] 1:* fLancamentosRealizados[ContaID]
- dPlanoContas[ContaID] 1:* fOrcamento[ContaID]
- dCentroCusto[CentroCustoID] 1:* fLancamentosRealizados[CentroCustoID]
- dCentroCusto[CentroCustoID] 1:* fOrcamento[CentroCustoID]
Use direção de filtro única, das dimensões para as fatos. Marque dCalendario como tabela de datas.
